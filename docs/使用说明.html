Cursor 完整汉化工具分享：一键把界面变成中文

💡操作提示：本工具面向日常使用 Cursor 的用户，在不修改 Cursor 核心程序的前提下，将界面中的英文菜单、按钮、提示和说明替换为中文，降低阅读和操作成本。已实现 编辑器模式（Editor）和 智能体模式（Agent）两种界面的全面汉化。

工具介绍

Cursor 官方目前尚未提供中文界面或汉化包，常见做法是安装VSCode汉化插件实现部分汉化，菜单、通用设置等会变成中文，但智能体侧栏、Cursor 设置、插件市场等 Cursor 专有界面 往往仍是英文，给习惯使用中文界面的用户增加了学习和使用成本。

Cursor 完整汉化工具 的做法是在自动安装VSCode汉化包的同时，向工作台注入带词典的运行时脚本，把Cursor专有界面也替换成中文，让日常使用的界面尽量一眼能读懂。工具已实现编辑器模式（Editor）和智能体模式（Agent）两种界面的全面汉化。

https://www.vibepm.net/cursor/

覆盖区域：

  • 设置页：账户、模型、规则、工具与 MCP、隐私等选项
  • 智能体窗口：对话、命令面板、模式切换（计划 / 询问 / 调试 / 多任务）等
  • 插件市场：插件名称、简介、获取按钮及市场相关文案
  • 其它界面：欢迎页、Git 变更面板、部分通知与推广弹窗等

主要特点：

  • 自动安装VSCode汉化包：一键自动安装VSCode汉化扩展（覆盖标准菜单、通用设置等），如有更新，将自动根据版本下载匹配的语言包并安装，省去自己去扩展市场手动搜索、安装语言包的步骤。
  • 双层汉化，覆盖面更全：通过注入脚本 + 本地词典，完整翻译 Cursor 专有界面，例如智能体侧栏、Cursor 设置（账户 / 模型 / 规则 / MCP）、插件市场、欢迎页、Git 面板及部分通知弹窗等。
  • 不改动核心程序，可一键还原：只修改工作台相关文件（如 workbench.html），需要英文时运行「取消汉化」脚本即可恢复，已装的VsCode汉化包可保留。
  • 维护成本低：Cursor 小版本更新后若有个别位置变回英文，再运行一次启动脚本即可，一般无需重装软件。
  • 其它说明：日常点得到的界面大多已是中文；个别菜单、动态文案或新版本新增词条可能仍为英文，可在词典中补充后重新注入。Agent 对话与模型生成内容不属于界面汉化范围。

如何使用

图形界面版（推荐，免 Python）

下载 CursorHanhua.exe（Releases 附件），双击即用：单文件、免安装、不需要 Python。界面里三个按钮即可完成全部操作：

  • 启动汉化：安装/更新官方语言包、注入词典脚本、同步校验值
  • 取消汉化：从备份恢复工作台文件（需二次点击确认）
  • 修复校验：重新写入校验值，解决「安装已损坏」提示

程序会自动定位 Cursor 安装目录（含 C 盘以外的盘符），装在其他位置可点顶部路径手动指定；运行日志实时显示引擎输出。若 Cursor 装在 Program Files 且当前账号无写权限，界面会提示并支持一键「以管理员身份重启」。

脚本版（需要 Python 3.8+）

汉化工具依赖 Python 3.8+（Windows 通过 启动汉化_Win.bat 调用，Mac/Linux 通过 shell 脚本调用）。

  1. 下载并解压汉化工具（内含 启动汉化_Win.bat / 启动汉化_Mac.sh 等）。
  2. Windows：双击 启动汉化_Win.bat。Mac / Linux：在终端执行 启动汉化_Mac.sh。
  3. 脚本会安装语言包并注入汉化，按提示可选打开 Cursor。
  4. 完全退出并重启 Cursor（不要只重载窗口）。

Mac在终端中运行汉化脚本：

  1. 打开终端：按 Cmd + 空格，输入「终端」后回车。
  2. 在终端输入 bash加空格，再把 启动汉化_Mac.sh 拖入窗口补全路径后回车，输入Y进行汉化。

若安装后顶部菜单仍为英文，请手动切换显示语言：

  1. 按 Ctrl+Shift+P（macOS：Cmd+Shift+P）打开命令面板
  2. 输入 Configure Display Language，选择 配置显示语言
  3. 在列表中选择 中文(简体)（zh-cn）
  4. 按提示完全退出并重启 Cursor

恢复英文

Windows 双击 取消汉化_Win.bat； Mac / Linux 运行 取消汉化_Mac.sh；

同样要完全退出并重启。语言包会保留，只是撤销注入、恢复备份文件。

常见问题

  • 更新 Cursor 后汉化失效了：重新再运行一次汉化脚本即可。
  • 已经执行汉化但是没有生效：确认已完全重启了 Cursor。
  • 运行脚本报错 / 弹出 Microsoft Store / 汉化无输出：通常是未安装真正的 Python。运行 where python，若路径含 Microsoft\WindowsApps，请从 python.org 安装 Python 3 并勾选 Add python.exe to PATH，或执行 winget install Python.Python.3.12；安装后重开终端，用 python --version 确认。
  • 提示「安装已损坏 / installation appears to be corrupt」：汉化会修改 workbench.html，Cursor 还会校验 product.json 中的全部 checksum（约 6 个核心文件）。请运行 修复校验_Win.bat（Mac/Linux 用 修复校验_Mac.sh），或执行 python Cursor_Localization_Tool.py --fix-checksum。若提示权限不足，Windows 请右键以管理员身份运行；完成后完全退出并重启 Cursor。
  • 汉化后顶部菜单仍是英文：按 Ctrl+Shift+P（Mac 用 Cmd+Shift+P）→ 输入「Configure Display Language」→ 选 中文(简体) / zh-cn → 再完全重启一次。如果没有中文(简体)选项，在扩展市场中搜索并“ Chinese (Simplified) Language Pack"后重新设置。
  • 双击 .bat 闪退、乱码或提示「不是内部或外部命令」：脚本被保存成了 LF 换行或 UTF-8 编码，cmd 无法正确解析。请使用本仓库原始的 .bat（CRLF + GBK 编码）；自行修改后请用记事本另存为 ANSI 编码 + Windows(CRLF) 换行。
  • 找不到 Cursor 安装目录：脚本会自动检查常见安装路径，以及 C~H 盘下的 Program Files\Cursor、Program Files (x86)\Cursor、Cursor、Programs\Cursor。若仍未找到，用记事本打开目录中的 启动汉化_Win.bat，在文件开头 cd /d "%~dp0"后面增加一行，指定 Cursor 安装目录，保存后重新运行启动脚本。
    • 
set "CURSOR_INSTALL_DIR=D:\Program Files\cursor"   # 含 Cursor.exe 的安装文件夹
  • 执行脚本时仍然出错：直接将汉化脚本拖入到cursor的对话框中，发送： 
    
我需要安装这个汉化工具，汉化时出现了报错，帮我检查并重新执行脚本，我安装目录是：XXX
